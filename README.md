#ChatGPT 对话导航器

一款用于提升 ChatGPT 长对话使用体验的 Edge / Chrome 浏览器扩展。

为长时间、多轮次的 ChatGPT 对话提供完整对话导航、快速节点跳转、快捷提示词和本地工作台。

> 当前版本：v2.5.3

---

## ✨ 主要功能

### 🧭 完整对话导航

在 ChatGPT 页面右侧显示对话进度导航。

- 显示用户发送过的全部消息节点
- 点击节点快速跳转到对应位置
- 支持超长对话
- 支持导航列表滚动
- 支持普通节点 / 关键节点区分
- 鼠标离开后自动隐藏

---

### 📚 长对话完整读取

插件优先读取 ChatGPT 页面已经获取到的 conversation 数据，用于建立完整的用户消息索引。

当内部数据读取不可用时，会自动回退到：

- DOM 页面扫描
- 历史节点缓存
- 页面滚动加载

因此不会完全依赖当前页面已经渲染出来的消息。

---

### ⚡ 快捷提示词

内置常用 ChatGPT 工作提示词，例如：

- 正式复盘
- 二次复盘
- 动作检查
- 项目卡规划
- 生成项目卡
- 封板检查

点击按钮即可自动填入 ChatGPT 输入框。

不会自动发送。

---

### ✏️ 快捷提示词编辑

支持自定义：

- 按钮名称
- 提示词内容
- 新增提示词
- 删除提示词
- 恢复默认

设置会保存在浏览器扩展本地存储中。

---

### 🗂 本地工作台

通过右侧导航打开工作台，可快速查看：

- 快捷提示词
- 对话节点
- 关键节点
- 当前对话消息数量
- 当前导航数据源

工作台和对话导航采用互斥显示，不会同时遮挡页面。

---

## 🖥 支持浏览器

主要测试环境：

- Microsoft Edge
- Google Chrome

要求浏览器支持 Manifest V3。

---

## 📦 安装方法

目前插件暂未发布到 Edge Add-ons 或 Chrome Web Store，需要手动安装。

### 1. 下载插件

进入 GitHub：

`Releases → 最新版本`

下载插件 ZIP。

### 2. 解压 ZIP

将下载的 ZIP 解压到固定文件夹。
